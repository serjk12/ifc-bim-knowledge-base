**Method:** each key claim (ISO/standard numbers and editions, IFC versions, release dates and versions, regulation numbers, entity/property names, menu paths, URLs) was compared with the most primary page reachable: buildingSMART GitHub repositories and release pages, the buildingSMART Validation Service user guide and forum release thread, official CORENET X pages and the circular PDF (text extracted with a PDF reader), gov.cn, the SAMR national standards platform, КонсультантПлюс (Urban Planning Code), and ISO catalogue mirrors (genorma.com, scc-ccn.ca, evs.ee) where iso.org returned 403. Nothing was downloaded to be installed or executed; only web pages and two PDFs saved by the fetch tool were read.

- The shared WebSearch budget ran out mid-session (a dozen searches in this pass, more by parallel agents). After that only direct page fetches were possible, so Russian Government decrees and several Chinese documents could not be re-verified.
- Unreachable or unusable: iso.org (403), technical.buildingsmart.org / buildingsmart.org / standards.buildingsmart.org (403 or snippets only), all `.gov.ru` hosts (pravo.gov.ru, minstroyrf.gov.ru, gge.ru, ksi.faufcc.ru: connection refused or title-only pages), docs.cntd.ru (refused), cn.gostinfo.ru (timeout), mohurd.gov.cn (DNS failure), Baidu Baike (403), Autodesk help for Revit 2026 (topic list only).
