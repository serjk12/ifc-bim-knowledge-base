IMPORTANT CAVEAT: the WebSearch budget was exhausted at the start of the run (all searches refused), so only direct WebFetch of site pages was possible. The 28 "real" records are real published Italian articles (vendor/trade blogs and regulation explainers); their `question_paraphrase` is the question each article answers, rephrased in a plausible user voice. They are NOT verbatim forum posts. No genuine user forum threads were obtained.

## Top themes (ranked by frequency)
- Obbligo BIM negli appalti pubblici (art. 43 D.Lgs. 36/2023, soglia 2 milioni, dal 1/1/2025) and transitional rules
- Capitolato informativo / offerta di gestione informativa (oGI) / piano (pGI), ISO 19650 and UNI 11337
- Revit-to-IFC export setup: class mapping, IfcExportAs, MVD (Coordination View 2.0), IFC2x3 vs IFC4
- Loss of properties/Pset on export and custom parameter mapping
- Coordinates, origin and georeferencing of IfcSite; models not overlapping
- Editing IFC: proxies, read-only viewers, GUID changes, round-tripping
- IFC validation / verifica informativa (FireRating, required properties)
- Comparing IFC revisions; BCF issue exchange
- Conversion DWG->IFC, IFC->DXF
- IFC 4.3 / infrastructure and IFC railway
- Fees and incentives linked to BIM (10% maggiorazione, 15% incentivi)
- ACDat / CDE for stazioni appaltanti and PAD platforms
- Units in IFC and schema-valid-but-wrong data

## What people want
- Know whether BIM/IFC is legally required for a given tender and how to comply
- Export clean IFC from Revit/Archicad without losing classes and properties
- Make models from different disciplines align (origin, georeference)
- Check deliverables against capitolato informativo before submission
- Edit or fix received IFC without breaking GUIDs
- Track changes between revisions and communicate issues via BCF
- Convert legacy DWG into IFC and extract 2D (DXF) from IFC

## How people write here
Observed only indirectly (articles, no forum posts), so these are inferred from titles/headings:
- Formal, procedural register; many titles are question-form ("quando deve essere rispettato?", "e obbligatoria?").
- Heavy English code-switching: "export", "class mapping", "Pset", "viewer", "proxy", "clash detection", "workflow".
- Institutional jargon: stazione appaltante, DOCFAP, ACDat (ambiente di condivisione dati), capitolato informativo, oGI/pGI, RTI, RUP.
- Fragments: "IFC VS RVT: quali sono le differenze"; "IFC class mapping file"; "Come creare un file IFC".
