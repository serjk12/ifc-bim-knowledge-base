# IFC / BIM Knowledge Base — как люди на самом деле работают с IFC и Revit

> 🚧 **Идёт сборка.** Ночью 6 ноября 2026 сотни агентов исследуют форумы, регламенты, госстандарты и open source по всему миру.
> Файлы появляются здесь автоматически примерно каждые 20 минут. Когда сборка закончится, этот README заменится полным оглавлением.
>
> 🚧 **Work in progress.** Hundreds of research agents are collecting material worldwide; files are pushed here automatically every ~20 minutes.

## Зачем это

База знаний для тех, кто **тестирует MCP-серверы и AI-ассистентов, работающих с форматом IFC (Industry Foundation Classes), Revit и openBIM**.
Главная цель: чтобы языковая модель могла составлять **вопросы и задачи, которые звучат как запросы реальных людей**: BIM-координаторов, архитекторов, инженеров, сметчиков, разработчиков и студентов. А не как выдуманные «учебные» вопросы.

| `02_standards_regulations/` | buildingSMART (IFC, IDS, BCF, bSDD, MVD), ISO 16739 / 19650, **национальные регламенты** разных стран (РФ: СП 328/331/333, ГОСТ Р 10.0.03, ЦИМ для экспертизы, КСИ; Китай: GB/T; Сингапур: IFC-SG; Великобритания, Германия, Бразилия, Чили и др.) |

| `07_mcp_testing/` | ⭐ таксономия намерений, сценарии тестов, ловушки, критерии оценки, готовый промпт для генерации вопросов |
